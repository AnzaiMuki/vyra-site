# VYRA — site vitrine

Site statique de présentation de **VYRA** (VYRA Camera + VYRA Studio) :
régie multi-caméras à partir de téléphones (NDI / SRT), pour églises et production live.

- **Statique** : `index.html` + `styles.css` + `main.js` + `assets/`. Aucun build.
- **Déploiement** : Vercel (projet lié à ce dépôt) ou tout hébergeur de fichiers statiques.
- **Paiement** : achat des licences via **FedaPay** (liens à renseigner dans `main.js` → `FEDAPAY`).
  Sans lien configuré, les boutons basculent sur WhatsApp.
- **Prix** : affichés en FCFA. Licence perpétuelle, par poste.
